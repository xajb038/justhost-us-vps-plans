## 这里的“不限流量”指什么

JustHost 的计费方式是按端口速率卖，不按月流量 GB 数卖。官网在每档套餐下都标了一行换算：10Mbps 端口“相当于每月 4TB 以上”，100Mbps 相当于 31TB 以上，300Mbps 相当于 93TB 以上，750Mbps 相当于 232TB 以上。

换算逻辑是端口满速跑满整月的理论值。实际使用受 fair-share 约束：物理机带宽由同宿主机上的 VPS 共享，长时间占满端口会被调度限速。所以“不限流量”的准确含义是不按 GB 计费、不会因为跑超某个数字被停机或另外收钱，不等于独占 300Mbps 跑一个月。

这种模型和另一种常见做法正好相反。有的商家给 500Mbps 大端口但设 1TB 月流量上限，超了限速到 1Mbps、次月 1 日重置，建站场景下 1Mbps 基本等于断网。JustHost 这种按端口算的方式对流量忽高忽低的项目更友好，代价是高峰期共享带宽可能有波动。两种模型没有绝对优劣，取决于你的项目是持续跑满带宽，还是偶尔突发。

## 官网 FAQ 里才写的几条限制

产品页讲配置，FAQ 讲代价。下面几条只在问答里出现，买之前值得逐条确认：

**没有自动备份。** 官网写得很直白：JustHost 不提供自动备份，需要用户自建备份服务器，把副本放在另一台机器上。这条影响很大。跑数据库或独立站的人，要在预算里额外算一台低配 VPS 做备份目标，或者至少配一个对象存储定时同步。默认以为“云主机自带快照”的人会在这里踩坑。

**DDoS 防护是内置的。** 全系 VPS 带 DDoS 过滤，多层机制监测异常流量并在攻击开始时拦截。这一项不额外收费，也不需要单独配置。

**端口带宽是共享的。** 前面已经说过，fair-share 意味着同宿主机上的邻居会互相影响。做直播推流、大文件分发这类持续吃带宽的业务，要按标称端口的六到七成估实际可用值。

**退款和支付方式官网没有明确条款。** 公开页面里没有写退款期限，也没有列支持的付款渠道。这两项直接决定试错成本和付款便利性，下单前用在线客服问清楚：多少天内可以退、退款扣不扣手续费、能不能用支付宝或 PayPal。别默认“美国商家都支持 PayPal”，也别默认“都能 3 天无理由”。

**更高配型号经常缺货。** Rigel 以上的型号在总览页有展示，但不一定随时可开。要等高配补货的话，先用低一档跑着，比干等更实际。
